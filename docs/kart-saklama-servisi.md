# Kart Saklama Servisi

- [Kart Kaydetme](kart-saklama-servisi/kart-kaydetme.md): PCI DSS Level 1 sertifikalı Paywall servisleri
- [1. Yeni Kart](kart-saklama-servisi/kart-kaydetme/1.-yeni-kart.md): Yeni kart ekleme işlemini sadece sunucularınız (Back-End) üzerinden gerçekleştirmeniz önerilir. Uygulamalarınızdan (Son Kullanıcı) direkt erişim sağlamanız önerilmez.
- [2. Kayıtlı Kartlar](kart-saklama-servisi/kart-kaydetme/2.-kayitli-kartlar.md): Kayıtlı kart verilerini sadece sunucularınız (Back-End) üzerinden çekmeniz önerilir. Uygulamalarınızdan (Son Kullanıcı) direkt erişim sağlamanız önerilmez.
- [3. Kart Sil](kart-saklama-servisi/kart-kaydetme/3.-kart-sil.md): Kayıtlı kartı silme işlemini sadece sunucularınız (Back-End) üzerinden gerçekleştirmeniz önerilir. Uygulamalarınızdan (Son Kullanıcı) direkt erişim sağlamanız önerilmez.
- [4. Kart Güncelle](kart-saklama-servisi/kart-kaydetme/4.-kart-guncelle.md): Kayıtlı kartı güncelleme işlemini sadece sunucularınız (Back-End) üzerinden gerçekleştirmeniz önerilir. Uygulamalarınızdan (Son Kullanıcı) direkt erişim sağlamanız önerilmez.
