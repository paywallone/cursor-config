# 3. İndirim

- [1. İndirim Bilgisini Getir](3.-indirim/1.-indirim-bilgisini-getir.md): Ödeme'nin ürününe uygulanan indirim bilgisini bu servis aracılığıyla tekrar alabilirsiniz.
- [2. İndirim Tanımla](3.-indirim/2.-indirim-tanimla.md): Ödeme anında indirim tanımı yapabildiğiniz gibi sonrasında da ilgili ürünlerinize indirim tanımlayabilirsiniz.
