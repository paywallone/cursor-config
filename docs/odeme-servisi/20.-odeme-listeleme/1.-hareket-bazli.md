# 1. Hareket Bazlı

## Hareket Bazlı

<mark style="color:blue;">`GET`</mark> `{{Private Base Address}}/api/paywall/private/vpos/transaction/list/activity`

{% hint style="info" %}
Önemli: **Ödeme Listeleme - Hareket Bazlı** servisini kullanabilmeniz için 'Header' alanında '**apikeyprivate**' ve '**apiclientprivate**' parametrelerini göndermeniz gerekmektedir.\
\
[<mark style="color:green;">**PaymentPrivateAPI Adresi**</mark>](https://developer.paywall.one/ortam)
{% endhint %}

{% hint style="warning" %}
**Ödeme Listeleme - Hareket Bazlı** servisi, yalnızca en yakın **T-1** gününün tamamlanmış işlemlerini listeler. Gün sonu tamamlanmamış işlemler bu serviste yer almaz.
{% endhint %}

{% hint style="danger" %}
Bu servisteki 🗓️ `date` parametresi, filtreleme sırasında işlem adımlarının (satış, iptal, iade, kısmi iade) tarihlerini esas alarak çalışmaktadır.
{% endhint %}
