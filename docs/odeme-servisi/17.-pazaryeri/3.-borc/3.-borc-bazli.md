# 3. Borç Bazlı

- [1. Borç Arttır](3.-borc-bazli/1.-borc-arttir.md): Ödemelerinizde oluşan (Kargo, İndirim vb durumlarda) alt üye işyeri borçlarını, ek yeni maliyetlerden çıkması durumunda arttırabilirsiniz.
- [2. Borç Azalt](3.-borc-bazli/2.-borc-azalt.md): Ödemelerinizde oluşan (Kargo, İndirim vb durumlarda) alt üye işyeri borçlarını, istediğiniz durumlarda azaltabilirsiniz.
- [3. Borç Sil](3.-borc-bazli/3.-borc-sil.md): Ödemelerinizde oluşan (Kargo, İndirim vb durumlarda) alt üye işyeri borçlarını, istediğiniz durumlarda silebilirsiniz.
