# 3. Borç Sil

## Borç Sil

<mark style="color:red;">`DELETE`</mark> `{{Base Adres}}/api/paywall/marketplace/debt/delete/id`

{% hint style="info" %}
Önemli: **Borç Sil** servisini kullanabilmeniz için 'Header' alanında '**apikeypublic**' ve '**apiclientpublic**' parametrelerini göndermeniz gerekmektedir.\
\
[<mark style="color:green;">**PaymentAPI Adresi**</mark>](https://developer.paywall.one/ortam)
{% endhint %}

{% hint style="warning" %}
İlgili işlemi yapabilmeniz için borcun yatmamış olması gerekmektedir. Aksi halde Paywall servisi hata mesajı dönecektir.
{% endhint %}
