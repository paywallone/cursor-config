# 3. Sorgula

## Ödeme Emri Başlat

<mark style="color:blue;">`GET`</mark> `{{Base Adres}}/api/paywall/marketplace/manual/trigger/inquiry`

{% hint style="info" %}
Önemli: **Ödeme Emri Takibi** servisini kullanabilmeniz için 'Header' alanında '**apikeypublic**' ve '**apiclientpublic**' parametrelerini göndermeniz gerekmektedir.\
\
[<mark style="color:green;">**PaymentAPI Adresi**</mark>](https://developer.paywall.one/ortam)
{% endhint %}

<table><thead><tr><th width="188">Parametre</th><th width="79">Tip</th><th width="107">Zorunlu</th><th width="403">Açıklama</th></tr></thead><tbody><tr><td>apikeypublic</td><td>string</td><td>Evet</td><td>Üye işyeri panelinden temin etmiş olduğunuz Public Key.</td></tr><tr><td>apiclientpublic</td><td>string</td><td>Evet</td><td>Üye işyeri panelinden temin etmiş olduğunuz Public Client.</td></tr><tr><td>jobid</td><td>Guid</td><td>Evet</td><td>Ödeme emri takip numarasıdır ve başlatma emrindeki isteğinize Paywall'dan gelen cevap içerisinde JobId parametresi olarak dönülmektedir</td></tr></tbody></table>
