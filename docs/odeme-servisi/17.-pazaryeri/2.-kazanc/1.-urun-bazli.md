# 1. Ürün Bazlı

- [1. Kazanç Getir](1.-urun-bazli/1.-kazanc-getir.md)
- [2. Kazanç Ertele](1.-urun-bazli/2.-kazanc-ertele.md): Id bilgisini bildiğiniz ürünlerin hesaplanmış kazançlarının yansıma tarihi öncesinde uzatabilir, ödemelerinizi erteleyebilirsiniz
- [3. Kazanç Arttır](1.-urun-bazli/3.-kazanc-arttir.md): Id bilgisini bildiğiniz ürünlerin hesaplanmış kazançlarının tutarlarını arttırabilirsiniz.
- [4. Kazanç Azalt](1.-urun-bazli/4.-kazanc-azalt.md): Id bilgisini bildiğiniz ürünlerin hesaplanmış kazançlarının tutarlarını azaltabilirsiniz.
- [5. Tarih Güncelle](1.-urun-bazli/5.-tarih-guncelle.md): Id bilgisini bildiğiniz ürünlerin hesaplanmış kazançlarının yatırılma tarihini güncelleyebilirsiniz.
- [6. Tekrar Dene](1.-urun-bazli/6.-tekrar-dene.md): Id bilgisini bildiğiniz ürünlerin gönderilmiş ve başarısız olmuş ödemelerini tekrar ödeme kuyruğuna almak için bu servisi kullanabilirsiniz
