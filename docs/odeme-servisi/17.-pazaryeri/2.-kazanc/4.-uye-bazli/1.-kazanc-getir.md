# 1. Kazanç Getir

## Üye Id ile kazanç bilgilerini getir

<mark style="color:blue;">`GET`</mark> `{{Base Adres}}/api/paywall/marketplace/report/earning/member`

{% hint style="info" %}
Önemli: Üye **Id ile Bazlı Kazanç** servisini kullanabilmeniz için 'Header' alanında '**apikeypublic**' ve '**apiclientpublic**' parametrelerini göndermeniz gerekmektedir.\
\
[<mark style="color:green;">**PaymentAPI Adresi**</mark>](https://developer.paywall.one/ortam)
{% endhint %}
