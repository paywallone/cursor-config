# 2. Kazanç Ertele

## Kazanç kimliğiyle (EarningId) kazanç erteleme

<mark style="color:orange;">`PUT`</mark> `{{Base Adres}}/api/paywall/marketplace/earning/postpone/id`

{% hint style="info" %}
Önemli: **Kazanç Erteleme** servisini kullanabilmeniz için 'Header' alanında '**apikeypublic**' ve '**apiclientpublic**' parametrelerini göndermeniz gerekmektedir.\
\
[<mark style="color:green;">**PaymentAPI Adresi**</mark>](https://developer.paywall.one/ortam)
{% endhint %}

{% hint style="warning" %}
İlgili işlemi yapabilmeniz için kazancın yatmamış olması gerekmektedir. Aksi halde Paywall servisi hata mesajı dönecektir.
{% endhint %}

<table><thead><tr><th width="188">Parametre</th><th width="79">Tip</th><th width="107">Zorunlu</th><th width="403">Açıklama</th></tr></thead><tbody><tr><td>apikeypublic</td><td>string</td><td>Evet</td><td>Üye işyeri panelinden temin etmiş olduğunuz Public Key.</td></tr><tr><td>apiclientpublic</td><td>string</td><td>Evet</td><td>Üye işyeri panelinden temin etmiş olduğunuz Public Client.</td></tr></tbody></table>
