# 6. Tekrar Dene

## Kazanç bazlı tekrar dene

<mark style="color:orange;">`PUT`</mark> `{{Base Adres}}/api/paywall/marketplace/earning/put/retry/product`

{% hint style="info" %}
Önemli: **Kazanç Bazlı Tekrar Dene** servisini kullanabilmeniz için 'Header' alanında '**apikeypublic**' ve '**apiclientpublic**' parametrelerini göndermeniz gerekmektedir.\
\
[<mark style="color:green;">**PaymentAPI Adresi**</mark>](https://developer.paywall.one/ortam)
{% endhint %}

<table><thead><tr><th width="188">Parametre</th><th width="79">Tip</th><th width="107">Zorunlu</th><th width="403">Açıklama</th></tr></thead><tbody><tr><td>apikeypublic</td><td>string</td><td>Evet</td><td>Üye işyeri panelinden temin etmiş olduğunuz Public Key.</td></tr><tr><td>apiclientpublic</td><td>string</td><td>Evet</td><td>Üye işyeri panelinden temin etmiş olduğunuz Public Client.</td></tr></tbody></table>

**Servise gönderilmesi gereken parametreler şu şekildedir:**

<table><thead><tr><th width="240">Parametre</th><th width="125.33333333333331">Tip</th><th>Açıklama</th></tr></thead><tbody><tr><td>Id</td><td>int</td><td>Kazanca ait Id (kimlik) bilgisi</td></tr><tr><td>ChangeReflectionDate</td><td>bool</td><td>Hakediş gönderiminin hangi tarihte gerçekleşeceğini değiştirmek istiyorsanız 'True' gönderebilirsiniz</td></tr><tr><td>ReflectionDate</td><td>DateTime</td><td>Kazancın yatmasını istediğiniz tarih bilgisi</td></tr></tbody></table>
