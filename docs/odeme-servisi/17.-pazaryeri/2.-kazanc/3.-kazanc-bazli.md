# 3. Kazanç Bazlı

- [1. Kazanç Getir](3.-kazanc-bazli/1.-kazanc-getir.md)
- [2. Kazanç Ertele](3.-kazanc-bazli/2.-kazanc-ertele.md): Kazanç kayıtlarınızı listeleyebilir, ilgili kaydın alt üye işyerine yansıması öncesinde kazancın yansıma tarihini uzatabilirsiniz.
- [3. Kazanç Arttır](3.-kazanc-bazli/3.-kazanc-arttir.md): Kazanç kayıtlarınızı listeleyebilir, ilgili kazancın tutarını arttırabilirsiniz
- [4. Kazanç Azalt](3.-kazanc-bazli/4.-kazanc-azalt.md): Kazanç kayıtlarınızı listeleyebilir, ilgili kazancın tutarını azaltabilirsiniz
- [5. Tarih Güncelle](3.-kazanc-bazli/5.-tarih-guncelle.md): Kazanç kayıtlarınızı listeleyebilir, istediğiniz kazancın yatırılacağı tarihi güncelleyebilirsiniz
- [6. Tekrar Dene](3.-kazanc-bazli/6.-tekrar-dene.md): Kazanç Id bilgisini bildiğiniz hak ediş ödemelerini tekrar ödeme kuyruğuna almak için bu servisi kullanabilirsiniz
