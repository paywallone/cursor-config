# 5. Sorgula / Özet

## **Toplu Ödeme Özet Sorgulama Servisi**

<mark style="color:blue;">`GET`</mark> `{{Base Adres}}/api/paywall/payment/bulk/payment/query/summary`

{% hint style="info" %}
**Önemli:** Toplu ödeme özet sorgulama servisini kullanabilmeniz için **Header** alanında **apikeypublic** ve **apiclientpublic** parametrelerini göndermeniz gerekmektedir.

[<mark style="color:green;">**PaymentAPI Adresi**</mark>](https://developer.paywall.one/ortam)
{% endhint %}

**Servise gönderilmesi gereken parametreler şu şekildedir:**

İşlem başlatma anında parametre olarak Paywall'a gönderilir</td></tr></tbody></table>
