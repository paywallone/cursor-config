# DirectPay Tabanlı

APM alanında desteklenen ve Paywall üzerinden bağlantı kurduğunuz sağlayıcılar üzerinden, kullanıcınızın kullandığı sağlayıcı özelinde ödemenin 2. bir adıma uğramadan (destekleniyorsa) gerçekleşmesini sağlayabilirsiniz.

İlgili yöntemin ödemenin gerçekleştirilmek istendiği sağlayıcıda geçerli olması gerekmektedir.
