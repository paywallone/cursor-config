# 8. Bağlantı Kopar

## Bağlantı Kopar

<mark style="color:green;">`POST`</mark> `{{Base Adres}}/api/paywall/apm/unlink`

{% hint style="info" %}
Önemli: **Bağlantı Kopar** servisini kullanabilmeniz için 'Header' alanında '**apikeypublic**' ve '**apiclientpublic**' parametrelerini göndermeniz gerekmektedir.\
\
[<mark style="color:green;">**PaymentAPI Adresi**</mark>](https://developer.paywall.one/ortam)
{% endhint %}

#### Servise gönderilmesi gereken header parametreleri şu şekildedir :

<table><thead><tr><th width="221">Parametre (Headers)</th><th width="79">Tip</th><th width="106">Zorunlu</th><th width="403">Açıklama</th></tr></thead><tbody><tr><td>apikeypublic</td><td>string</td><td>Evet</td><td>Üye işyeri panelinden temin etmiş olduğunuz Public Key.</td></tr><tr><td>apiclientpublic</td><td>string</td><td>Evet</td><td>Üye işyeri panelinden temin etmiş olduğunuz Public Client.</td></tr></tbody></table>

**Servise gönderilmesi gereken (BODY) parametreler şu şekildedir:**

<table><thead><tr><th width="183">Parametre</th><th width="107">Tip</th><th width="141">Zorunlu</th><th width="336">Açıklama</th></tr></thead><tbody><tr><td>Phone</td><td>string</td><td>Evet</td><td>Ödeyicinin telefon numarası</td></tr><tr><td>ApmConnectionId</td><td>int</td><td>Evet/Hayır</td><td>APM sağlayıcısının bağlantı kimlik bilgisi. Listeme esnasında döner.<br><br>* ApmKey kullanılmıyorsa zorunlu</td></tr><tr><td>ApmKey</td><td>string</td><td>Evet/Hayır</td><td>APM sağlayıcısının Key bilgisi.<br><br>Bkz: <a href="../sistem-verileri/apm">APM</a><br><br>* ApmConnectionId kullanılmıyorsa zorunlu</td></tr></tbody></table>

```json
{
    "Phone": "905342979639",
    "ApmConnectionId": null,
    "ApmKey": "Masterpass_IFrame"
}
```
