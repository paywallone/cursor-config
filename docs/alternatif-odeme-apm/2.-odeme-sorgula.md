# 2. Ödeme Sorgula

## Ödeme Sorgula

<mark style="color:blue;">`GET`</mark> `{{Base Adres}}/api/paywall/apm/query`

{% hint style="info" %}
Önemli: **APM Ödeme Sorgulama** servisini kullanabilmeniz için 'Header' alanında '**apikeypublic**' ve '**apiclientpublic**' parametrelerini göndermeniz gerekmektedir.\
\
[<mark style="color:green;">**PaymentAPI Adresi**</mark>](https://developer.paywall.one/ortam)
{% endhint %}

#### Servise gönderilmesi gereken parametreler şu şekildedir :

<table><thead><tr><th width="221">Parametre (Headers)</th><th width="79">Tip</th><th width="106">Zorunlu</th><th width="403">Açıklama</th></tr></thead><tbody><tr><td>apikeypublic</td><td>string</td><td>Evet</td><td>Üye işyeri panelinden temin etmiş olduğunuz Public Key.</td></tr><tr><td>apiclientpublic</td><td>string</td><td>Evet</td><td>Üye işyeri panelinden temin etmiş olduğunuz Public Client.</td></tr><tr><td>merchantuniquecode</td><td>string</td><td>Evet</td><td>Ödeme başlatma anında ödemeye tanımladığınız tekil takip numarası</td></tr></tbody></table>

**Servisten dönen parametreler şu şekildedir:**
