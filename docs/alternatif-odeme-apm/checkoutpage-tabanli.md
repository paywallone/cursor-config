# CheckoutPage Tabanlı

APM alanında desteklenen ve Paywall üzerinden bağlantı kurduğunuz sağlayıcılar üzerinden, kullanıcınızın kullandığı sağlayıcı özelinde ödeme sayfası (CheckoutPage) oluşturabilirsiniz. Oluşturulan ödeme sayfası Paywall linkiyle birlikte size API cevabında iletilmektedir. Bu linki uygulamanızda açabilir ve kullanıcınızın ilgili ekranlarda ödeme yapmasını sağlayabilirsiniz.
