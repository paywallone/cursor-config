# 1. Bağlı Sağlayıcı Liste

## APM'lerimi listele

<mark style="color:blue;">`GET`</mark> `{{Base Adres}}/api/paywall/apm/list`

{% hint style="info" %}
Önemli: **APM Listeme** servisini kullanabilmeniz için 'Header' alanında '**apikeypublic**' ve '**apiclientpublic**' parametrelerini göndermeniz gerekmektedir.<br>

[<mark style="color:green;">**PaymentAPI Adresi**</mark>](https://developer.paywall.one/ortam)
{% endhint %}

#### Servise gönderilmesi gereken parametreler şu şekildedir :

<table><thead><tr><th width="211">Parametre (Headers)</th><th width="79">Tip</th><th width="106">Zorunlu</th><th width="403">Açıklama</th></tr></thead><tbody><tr><td>apikeypublic</td><td>string</td><td>Evet</td><td>Üye işyeri panelinden temin etmiş olduğunuz Public Key.</td></tr><tr><td>apiclientpublic</td><td>string</td><td>Evet</td><td>Üye işyeri panelinden temin etmiş olduğunuz Public Client.</td></tr><tr><td>currencyid</td><td>int</td><td>Evet</td><td>Ödeme'nin gerçekleştirilmek istendiği para birimi</td></tr><tr><td>externalid</td><td>string</td><td>Hayır</td><td>APM bağlantı anında verilen Dış Kimlik (ExternalId) bilgisi</td></tr><tr><td>focusedfeature</td><td>string</td><td>Hayır</td><td>Ödeme akışının hangi özellikte gerçekleştirilmek istendiği bildirilir. Örnek: qr iletilirse Paywall hesabında QR'lı ödeme destekleyen sağlayıcı listesi paylaşılır.<br><br>Bkz: <a href="../sistem-verileri/apm">Liste</a></td></tr><tr><td>distinctduplicates</td><td>bool</td><td>Hayır</td><td><mark style="color:green;">True</mark> olarak gönderilmesi durumunda liste içerisinde çoklanan aynı sağlayıcıya ait bağlantılar teke indirgenir</td></tr></tbody></table>
