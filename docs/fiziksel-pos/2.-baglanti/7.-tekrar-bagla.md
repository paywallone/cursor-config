# 7. Tekrar Bağla

<mark style="color:orange;">`PUT`</mark> `{{Base Address}}/api/connection/reconnect`

Yukarıda verilmiş olan adrese istek atmanız yeterli olacaktır. Test ortamı ve Gerçek ortam için 'Base Address' istediğiniz gibi kullanabilirsiniz.

{% hint style="info" %}
Önemli: **Tekrar Bağla** servisini kullanabilmeniz için 'Header' alanında '**apikeyprivate**' ve '**apiclientprivate**' parametrelerini göndermeniz gerekmektedir.\
\
[<mark style="color:green;">**PhysicalAPI Adresi**</mark>](https://developer.paywall.one/ortam)
{% endhint %}
