# 3. Senkronize Et

{% hint style="info" %}
**Örnek Akış:** Şirketinize yeni 100 adet terminal daha konumlandırdınız. Paywall terminallerin senkronizasyonunu belli bir periyotta yapmaktadır ancak akışınız gereği senkronizasyonu tetikleyebilir. Paywall'un periyodunu beklemeden senkronizasyon emri verebilirsiniz
{% endhint %}

<mark style="color:green;">`POST`</mark> `{{Base Address}}/api/terminal/sync`

Yukarıda verilmiş olan adrese istek atmanız yeterli olacaktır. Test ortamı ve Gerçek ortam için 'Base Address' istediğiniz gibi kullanabilirsiniz.

{% hint style="info" %}
Önemli: **Terminal Senkronizasyon Emri** servisini kullanabilmeniz için 'Header' alanında '**apikeyprivate**' ve '**apiclientprivate**' parametrelerini göndermeniz gerekmektedir.\
\
[<mark style="color:green;">**PhysicalAPI Adresi**</mark>](https://developer.paywall.one/ortam)
{% endhint %}

#### Servise gönderilmesi gereken header bilgileri şu şekildedir:
