# 3. WalletOwner ile Getir

## **Cüzdan Kaydını** WalletOwnerId ile Tanımla&#x20;

<mark style="color:green;">`GET`</mark> `{{WalletUrl}}/api/v1/wallet/transaction/by/walletowner/:walletOwnerId?Page=1&PageSize=10&StartDate=2025-03-24T20:26:25.426Z&EndDate=2025-04-29T20:26:25.426Z&TransactionType=1`

{% hint style="info" %}
**Not**: Bu servisi çağırmadan önce, **apikeypublic** ve **apiclientpublic** parametrelerini **Header** kısmına eklemeniz gereklidir.

[<mark style="color:green;">**WalletAPI Adresi**</mark>](https://developer.paywall.one/ortam)
{% endhint %}

**Servise gönderilmesi gereken parametreler şu şekildedir:**
