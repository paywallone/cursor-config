# 13. Para Transferi (Wallet)

## Cüzdan 'Id' ile **Para Transferi**

<mark style="color:yellow;">`POST`</mark> `{{WalletUrl}}/api/v1/wallet/transfer`

{% hint style="info" %}
Not: Bu servisin kullanılabilmesi için **apikeypublic** ve **apiclientpublic** parametrelerinin Header alanına eklenmiş olması zorunludur.

\
[<mark style="color:green;">**WalletAPI Adresi**</mark>](https://developer.paywall.one/ortam)
{% endhint %}

**Servise gönderilmesi gereken parametreler şu şekildedir:**

<table><thead><tr><th width="162">Parametre</th><th width="79">Tip</th><th width="107">Zorunlu</th><th width="403">Açıklama</th></tr></thead><tbody><tr><td>apikeypublic</td><td>string</td><td>Evet</td><td>Servisi kullanabilmek için gerekli olan genel API anahtarı.</td></tr><tr><td>apiclientpublic</td><td>string</td><td>Evet</td><td>Servis erişimi için gerekli olan istemci kimliği.</td></tr></tbody></table>

## Servis İstek

|                     |         |                                             |
| ------------------- | ------- | ------------------------------------------- |
| SourceWalletId      | Guid    | Para'nın çıkacağı hesabın kimlik bilgisi    |
| DestinationWalletId | Guid    | Para'nın iletileceği hesabın kimlik bilgisi |
| Amount              | decimal | Transfer edilecek tutar                     |
| Description         | string  | İlgili işlemin açıklaması                   |
| ExternalReference   | string  | İşlemin takip referanse kodu                |
