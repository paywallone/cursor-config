# 15. Para Transfer (Wallet - Alias)

## Cüzdan Id ile Cüzdan Alias'a Para Transferi

<mark style="color:yellow;">`POST`</mark>`{{WalletUrl}}/api/v1/wallet/transfer/by/wallet/to/alias`&#x20;

{% hint style="info" %}
Not: Bu servisin kullanılabilmesi için **apikeypublic** ve **apiclientpublic** parametrelerinin Header alanına eklenmiş olması zorunludur.

\
[<mark style="color:green;">**WalletAPI Adresi**</mark>](https://developer.paywall.one/ortam)
{% endhint %}

**Servise gönderilmesi gereken parametreler şu şekildedir:**

<table><thead><tr><th width="162">Parametre</th><th width="79">Tip</th><th width="107">Zorunlu</th><th width="403">Açıklama</th></tr></thead><tbody><tr><td>apikeypublic</td><td>string</td><td>Evet</td><td>API erişimi için kullanılan herkese açık anahtar.</td></tr><tr><td>apiclientpublic</td><td>string</td><td>Evet</td><td>İstemciyi tanımlamak için kullanılan herkese açık anahtar.</td></tr></tbody></table>

## Servis İstek

|                  |         |                                          |
| ---------------- | ------- | ---------------------------------------- |
| SourceWalletId   | Guid    | Para'nın çıkacağı hesabın kimlik bilgisi |
| DestinationAlias | string  | Para'nın iletileceği hesap numarası      |
| Amount           | decimal | Transfer edilecek tutar                  |
| Description      | string  | İlgili işlemin açıklaması                |
