# 7. Dondur

## **Kayıt Üzerinde Dondurma İşlemi Uygulamak için Bilgi Gönder**

<mark style="color:yellow;">`POST`</mark> `{{WalletUrl}}/api/v1/wallet/freeze`&#x20;

{% hint style="info" %}
Not: Bu servisin kullanılabilmesi için **apikeypublic** ve **apiclientpublic** parametrelerinin Header alanına eklenmiş olması zorunludur.

[<mark style="color:green;">**WalletAPI Adresi**</mark>](https://developer.paywall.one/ortam)
{% endhint %}

**Servise gönderilmesi gereken parametreler şu şekildedir:**

<table><thead><tr><th width="162">Parametre</th><th width="79">Tip</th><th width="107">Zorunlu</th><th width="403">Açıklama</th></tr></thead><tbody><tr><td>apikeypublic</td><td>string</td><td>Evet</td><td>API üzerinden yapılan her istekte kullanılan doğrulama anahtarıdır.</td></tr><tr><td>apiclientpublic</td><td>string</td><td>Evet</td><td>API'yi kullanan istemcinin kimliğini doğrulamak için gönderilen açık anahtardır.</td></tr></tbody></table>

## Servis İstek

| Parametre   | Tip       | Açıklama                                                                                                                                                                                                                                                |
| ----------- | --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Id          | Guid      | Dondurulacak cüzdan hesabının kimlik bilgisi                                                                                                                                                                                                            |
| FrozenUntil | DateTime? | Boş geçildiğinde, ilgili hesabın dondurulması sizin tarafınızdan kaldırılana kadar hesap kullanılamaz. Eğer spesifik bir tarih verilirse de ilgili hesap verilen tarih/saate bilgisine kadar donuk kalır, sonrasında otomatik kullanılabilir hale gelir |
