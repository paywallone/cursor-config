# 9. Para Yatırma (Wallet)

## **Cüzdan 'Id' Bilgisiyle Para Yatır**

<mark style="color:yellow;">`POST`</mark> `{{WalletUrl}}/api/v1/wallet/deposit`&#x20;

{% hint style="info" %}
Not: Bu servisin kullanılabilmesi için **apikeypublic** ve **apiclientpublic** parametrelerinin Header alanına eklenmiş olması zorunludur.

\
[<mark style="color:green;">**WalletAPI Adresi**</mark>](https://developer.paywall.one/ortam)
{% endhint %}

**Servise gönderilmesi gereken parametreler şu şekildedir:**

<table><thead><tr><th width="162">Parametre</th><th width="79">Tip</th><th width="107">Zorunlu</th><th width="403">Açıklama</th></tr></thead><tbody><tr><td>apikeypublic</td><td>string</td><td>Evet</td><td>API isteklerinde erişim izni sağlamak amacıyla kullanılan genel anahtar verisidir.</td></tr><tr><td>apiclientpublic</td><td>string</td><td>Evet</td><td>İstemcinin kimliğini doğrulamak için her istekte gönderilen açık kimlik anahtarıdır.</td></tr></tbody></table>

## Servis İstek

| Parametre         | Tip     | Açıklama                                                       |
| ----------------- | ------- | -------------------------------------------------------------- |
| Id                | Guid    | Para yatırılmak istenen cüzdanın kimlik bilgisi                |
| Amount            | decimal | Yatırılmak istenen tutar                                       |
| Description       | string  | İlgili işlemin açıklaması                                      |
| ExternalReference | string  | İşlemin takip numarası. Bu bilgiyle işlemi takip edebilirsiniz |
