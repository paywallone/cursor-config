# 16. Bakiye Sorgula (Wallet)

## Cüzdan 'Id' ile Bakiye Sorgula

<mark style="color:green;">`GET`</mark>`{{WalletUrl}}/api/v1/wallet/balance/by/id/0000-0000-0000-0000-0000`&#x20;

{% hint style="info" %}
Not: Bu servisin kullanılabilmesi için **apikeypublic** ve **apiclientpublic** parametrelerinin Header alanına eklenmiş olması zorunludur.

\
[<mark style="color:green;">**WalletAPI Adresi**</mark>](https://developer.paywall.one/ortam)
{% endhint %}

**Servise gönderilmesi gereken (Headers) parametreler şu şekildedir:**

<table><thead><tr><th width="162">Parametre</th><th width="79">Tip</th><th width="107">Zorunlu</th><th width="403">Açıklama</th></tr></thead><tbody><tr><td>apikeypublic</td><td>string</td><td>Evet</td><td>API erişimi için kullanılan genel anahtar bilgisidir.</td></tr><tr><td>apiclientpublic</td><td>string</td><td>Evet</td><td>API'ye bağlanan istemcinin kimliğini tanımlayan bilgidir.</td></tr></tbody></table>
