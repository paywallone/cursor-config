# 12. Para Çekme (Alias)

## **Cüzdan 'Alias' Bilgisiyle Para Yatır**

<mark style="color:yellow;">`POST`</mark> `{{WalletUrl}}/api/v1/wallet/withdraw/by/alias`&#x20;

{% hint style="info" %}
Not: Bu servisin kullanılabilmesi için **apikeypublic** ve **apiclientpublic** parametrelerinin Header alanına eklenmiş olması zorunludur.

\
[<mark style="color:green;">**WalletAPI Adresi**</mark>](https://developer.paywall.one/ortam)
{% endhint %}

**Servise gönderilmesi gereken parametreler şu şekildedir:**

<table><thead><tr><th width="162">Parametre</th><th width="79">Tip</th><th width="107">Zorunlu</th><th width="403">Açıklama</th></tr></thead><tbody><tr><td>apikeypublic</td><td>string</td><td>Evet</td><td>API erişimini doğrulamak için kullanılan genel anahtar bilgisidir.</td></tr><tr><td>apiclientpublic</td><td>string</td><td>Evet</td><td>İstemciyi tanımlayan ve servis çağrısında kimlik doğrulaması sağlayan anahtar bilgisidir.</td></tr></tbody></table>

## Servis İstek

|                   |         |                                                                |
| ----------------- | ------- | -------------------------------------------------------------- |
| Amount            | decimal | Para çekilmek istenen tutar                                    |
| Description       | string  | İlgili işlemin açıklaması                                      |
| Alias             | string  | Cüzdan'a tanımlanmış hesap numarası (1234567890)               |
| ExternalReference | string  | İşlemin takip numarası. Bu bilgiyle işlemi takip edebilirsiniz |
