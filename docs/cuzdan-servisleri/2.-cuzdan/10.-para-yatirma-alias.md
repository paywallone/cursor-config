# 10. Para Yatırma (Alias)

## **Cüzdan 'Alias' Bilgisiyle Para Yatır**

<mark style="color:yellow;">`POST`</mark> `{{WalletUrl}}/api/v1/wallet/deposit/by/alias`&#x20;

{% hint style="info" %}
Not: Bu servisin kullanılabilmesi için **apikeypublic** ve **apiclientpublic** parametrelerinin Header alanına eklenmiş olması zorunludur.

\
[<mark style="color:green;">**WalletAPI Adresi**</mark>](https://developer.paywall.one/ortam)
{% endhint %}

**Servise gönderilmesi gereken parametreler şu şekildedir:**

<table><thead><tr><th width="162">Parametre</th><th width="79">Tip</th><th width="107">Zorunlu</th><th width="403">Açıklama</th></tr></thead><tbody><tr><td>apikeypublic</td><td>string</td><td>Evet</td><td>API'ye yapılan çağrılarda kimlik doğrulaması amacıyla kullanılan açık anahtar değeridir.</td></tr><tr><td>apiclientpublic</td><td>string</td><td>Evet</td><td>İstemcinin sistemde tanımlı kimliğini temsil eden genel anahtar bilgisidir.</td></tr></tbody></table>

{% tabs %}
{% tab title="Servis İstek - Json" %}

```json
{
  "Amount": 1,
  "Description": "description",
  "Alias": "{{alias}}",
  "ExternalReference": "123321-123321-123321-123321"
}
```

{% endtab %}

## Servis İstek

| Parametre         | Tip     | Açıklama                                                       |
| ----------------- | ------- | -------------------------------------------------------------- |
| Amount            | decimal | Yatırılmak istenen tutar                                       |
| Description       | string  | İlgili işlemin açıklaması                                      |
| Alias             | string  | Cüzdan'a tanımlanmış hesap numarası (1234567890)               |
| ExternalReference | string  | İşlemin takip numarası. Bu bilgiyle işlemi takip edebilirsiniz |
