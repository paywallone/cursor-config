# 2. Getir (By-Alias)

## Alias Bilgisine Göre Kayıt Getir &#x20;

<mark style="color:green;">`GET`</mark>`{{WalletUrl}}/api/v1/wallet/by/alias/:alias`

{% hint style="info" %}
Not: Bu servisten faydalanmadan önce **apikeypublic** ve **apiclientpublic** parametrelerinin Header alanına eklenmesi zorunludur.

[<mark style="color:green;">**WalletAPI Adresi**</mark>](https://developer.paywall.one/ortam)
{% endhint %}

**Servise gönderilmesi gereken parametreler şu şekildedir:**

<table><thead><tr><th width="162">Parametre</th><th width="79">Tip</th><th width="107">Zorunlu</th><th width="403">Açıklama</th></tr></thead><tbody><tr><td>apikeypublic</td><td>string</td><td>Evet</td><td>API çağrılarında kimlik doğrulaması sağlamak için kullanılan ortak anahtar bilgisidir.</td></tr><tr><td>apiclientpublic</td><td>string</td><td>Evet</td><td>API'yi kullanan istemcinin kimliğini göstermek için gönderilen açık anahtar bilgisidir.</td></tr></tbody></table>
