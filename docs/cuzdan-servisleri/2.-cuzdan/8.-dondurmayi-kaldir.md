# 8. Dondurmayı Kaldır

## **Kayıt Üzerindeki Dondurma İşlemini Kaldırmak İçin Bilgi Gönder**

<mark style="color:yellow;">`POST`</mark> `{{WalletUrl}}/api/v1/wallet/unfreeze`&#x20;

{% hint style="info" %}
Not: Bu servisin kullanılabilmesi için **apikeypublic** ve **apiclientpublic** parametrelerinin Header alanına eklenmiş olması zorunludur.

[<mark style="color:green;">**WalletAPI Adresi**</mark>](https://developer.paywall.one/ortam)
{% endhint %}

**Servise gönderilmesi gereken parametreler şu şekildedir:**

<table><thead><tr><th width="162">Parametre</th><th width="79">Tip</th><th width="107">Zorunlu</th><th width="403">Açıklama</th></tr></thead><tbody><tr><td>apikeypublic</td><td>string</td><td>Evet</td><td>Servis isteklerinde kimlik doğrulaması için kullanılan açık anahtardır.</td></tr><tr><td>apiclientpublic</td><td>string</td><td>Evet</td><td>API'yi kullanan uygulamanın kimliğini tanımlayan public anahtar bilgisidir.</td></tr></tbody></table>
