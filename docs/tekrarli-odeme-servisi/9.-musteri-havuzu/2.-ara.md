# 2. Ara

## Tekrarlı Ödeme Müşteri Ara

<mark style="color:blue;">`GET`</mark> `{{Base Adres}}/api/paywall/recurring/customer/pool/search`

{% hint style="info" %}
Önemli: **Müşteri Arama** servisini kullanabilmeniz için 'Header' alanında '**apikeypublic**' ve '**apiclientpublic**' parametrelerini göndermeniz gerekmektedir.\
\
[<mark style="color:green;">**PaymentAPI Adresi**</mark>](https://developer.paywall.one/ortam)
{% endhint %}

<table><thead><tr><th width="162">Parametre</th><th width="122">Tip</th><th width="139">Zorunlu</th><th width="403">Açıklama</th></tr></thead><tbody><tr><td>apikeypublic</td><td>string</td><td>Evet</td><td>Üye işyeri panelinden temin etmiş olduğunuz Public Key.</td></tr><tr><td>apiclientpublic</td><td>string</td><td>Evet</td><td>Üye işyeri panelinden temin etmiş olduğunuz Public Client.</td></tr><tr><td>customername</td><td>string</td><td>Evet</td><td>Aramak istediğiniz müşteri ismi</td></tr></tbody></table>
