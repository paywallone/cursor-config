# 1. Liste

## Tekrarlı Ödeme Ürün/İçerik Havuz Listesi

<mark style="color:blue;">`GET`</mark> `{{Base Adres}}/api/paywall/recurring/item/pool`

{% hint style="info" %}
Önemli: **Ürün/İçerik Havuz Listeleme** servisini kullanabilmeniz için 'Header' alanında '**apikeypublic**' ve '**apiclientpublic**' parametrelerini göndermeniz gerekmektedir.\
\
[<mark style="color:green;">**PaymentAPI Adresi**</mark>](https://developer.paywall.one/ortam)
{% endhint %}
