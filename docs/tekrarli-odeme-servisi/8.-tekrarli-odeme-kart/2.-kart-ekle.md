# 2. Kart Ekle

## Tekrarlı Ödeme Kapsamına Yeni Kart Ekle

<mark style="color:green;">`POST`</mark> `{{Base Adres}}/api/paywall/recurring/card`

{% hint style="info" %}
Önemli: **Ödeme** servisini kullanabilmeniz için 'Header' alanında '**apikeypublic**' ve '**apiclientpublic**' parametrelerini göndermeniz gerekmektedir.\
\
[<mark style="color:green;">**PaymentAPI Adresi**</mark>](https://developer.paywall.one/ortam)
{% endhint %}

{% hint style="warning" %}
Kayıtlı bir kart **aynı tekrarlı ödeme üyeliğine** sadece bir sefer eklenebilir. Aynı kartı eklemek istediğinizde Paywall uyarı mesajı dönecektir
{% endhint %}

<table><thead><tr><th width="162">Parametre</th><th width="79">Tip</th><th width="107">Zorunlu</th><th width="403">Açıklama</th></tr></thead><tbody><tr><td>apikeypublic</td><td>string</td><td>Evet</td><td>Üye işyeri panelinden temin etmiş olduğunuz Public Key.</td></tr><tr><td>apiclientpublic</td><td>string</td><td>Evet</td><td>Üye işyeri panelinden temin etmiş olduğunuz Public Client.</td></tr></tbody></table>

<table><thead><tr><th width="186">Parametre</th><th width="112">Tip</th><th width="118">Zorunlu</th><th width="336">Açıklama</th></tr></thead><tbody><tr><td>SubscriptionId</td><td>int</td><td>Evet</td><td>Tekrarlı ödeme üyeliği oluşturma anında Paywall tarafından döner</td></tr><tr><td>UniqueCode</td><td>string</td><td>Evet</td><td>Ödemelerin alınacağı saklı kart UniqueCode bilgisi, kayıtlı kartlarda kaydetme anında ve listelemede cevap  olarak Paywall'dan döner</td></tr></tbody></table>
