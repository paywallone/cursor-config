# 3. Kart Sil

## Tekrarlı Ödeme Kapsamındaki Kartı Sil

<mark style="color:red;">`DELETE`</mark> `{{Base Adres}}/api/paywall/recurring/card`

{% hint style="info" %}
Önemli: **Ödeme** servisini kullanabilmeniz için 'Header' alanında '**apikeypublic**' ve '**apiclientpublic**' parametrelerini göndermeniz gerekmektedir.\
\
[<mark style="color:green;">**PaymentAPI Adresi**</mark>](https://developer.paywall.one/ortam)
{% endhint %}

{% hint style="warning" %}
Kart silme işleminin gerçekleştirilebilmesi için tekrarlı ödeme üyeliğinin pasif olması veya ilgili üyelik altında silinmek istenen kart haricinda başka bir kart daha olması gerekmektedır. Aksi taktirde Paywall hata mesajı üretir.
{% endhint %}
